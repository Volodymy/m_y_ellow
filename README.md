# Офіс AI-асистентів для паперової торгівлі

Бот торгує **віртуальними грошима** на реальних цінах. Він повторює підходи реальних трейдерів і фондів. Коду для торгівлі реальними грошима тут немає.

## Хто працює в «офісі»

| Агент | Роль |
|---|---|
| **Analyst** | запускає три стратегії й зводить їх в один цільовий портфель |
| **RiskManager** | ліміт 15% на актив, 2% кешу, без плеча; при просадці 25% переводить усе в кеш, далі потрібне ручне скидання |
| **Executor** (`PaperBroker`) | виконує угоди з комісіями й проковзуванням, зберігає рахунок у `data/paper_account.json` |
| **Reporter** | щоденний звіт; за бажанням коментар від Claude і відправка в Telegram |

Торгові рішення ухвалюють лише правила в коді. Claude тільки пояснює звіт людською мовою.

## Стратегії, на яких побудовано бота

| Рукав | Частка | На чому базується | Правила |
|---|---|---|---|
| `crypto_trend` | 30% | трендові CTA-фонди (Dunn, Winton, AHL), система Turtle | BTC/ETH/SOL/BNB: вхід на пробої 55-денного максимуму, вихід на пробої 20-денного мінімуму, розмір позиції за волатильністю |
| `etf_dual_momentum` | 30% | Gary Antonacci, *Dual Momentum* | раз на місяць 2 найсильніші ETF за 12 місяців; якщо вони слабші за короткі облігації, капітал іде в SHY |
| `superinvestor_clone` | 40% | звіти 13F: Berkshire Hathaway (Q3 2026) і консенсус ~80 суперінвесторів (Dataroma) | топ-10 позицій за вагою |

Звідки взято портфелі, описано в `config/superinvestors.yaml`.

## Результати бектесту на реальних даних (2020-01 → 2026-11)

Рукави `crypto_trend` і `etf_dual_momentum`. Угода виконується наступного дня після сигналу, з комісіями.

| | Дохід | CAGR | Sharpe | Макс. просадка |
|---|---|---|---|---|
| Увесь період | +220% | +18.4% | 1.45 | −19.9% |
| In-sample (до 2024-10) | +190% | +24.7% | 1.85 | −19.9% |
| **Out-of-sample (2024-10 → 2026-11)** | **+10.3%** | **+4.9%** | **0.46** | **−9.5%** |
| SPY за той самий out-of-sample період | +21.5% | +9.9% | 0.77 | −18.8% |
| BTC за той самий out-of-sample період | −14.9% | −7.5% | 0.05 | −53.6% |

**Висновок:** на «невидимих» даних останніх двох років стратегія відстала від простого утримання SPY, хоча просадка була вдвічі меншою. Це звичайна картина: красиві результати на минулому не гарантують нічого в майбутньому. Саме тому бот запускається в паперовому режимі.

Рукав 13F у бектест не входить: для чесної перевірки потрібні історичні звіти за кожен квартал, а прогін сьогоднішнього портфеля на минулих даних означав би заглядання в майбутнє.

## Запуск

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt

python -m office backtest              # бектест на реальних даних
python -m office backtest --synthetic  # без інтернету, лише перевірка механіки
python -m office run                   # один робочий день паперового рахунку (запускати раз на день)
python -m office status                # стан рахунку
python -m office reset                 # скинути рахунок і аварійну зупинку

# Оновити портфель фонду напряму з SEC EDGAR. SEC вимагає контакт у User-Agent:
SEC_USER_AGENT="Ваше Ім'я you@example.com" python -m office fetch-13f berkshire_hathaway

pytest -q
```

Усі параметри задаються в `config/settings.yaml`: частки рукавів, ліміти ризику, комісії, Claude і Telegram.

### Коментар Claude і Telegram (необов'язково)

У `config/settings.yaml` встановіть `reporter.llm_commentary: true` і/або `reporter.telegram: true`. Потім задайте змінні середовища: `ANTHROPIC_API_KEY` для Claude, `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID` для Telegram.

## Джерела даних

- Крипта: Binance public API (`data-api.binance.vision`)
- ETF і акції: Yahoo Finance (ціни з урахуванням дивідендів)
- 13F: SEC EDGAR (`data.sec.gov`, `www.sec.gov`)

## Чесні застереження

- Це дослідницький інструмент, а не інвестиційна порада.
- 13F публікується із затримкою до 45 днів і показує лише довгі позиції в акціях США.
- Рейтинги копітрейдерів на біржах мають ухил виживання: видно тих, хто ще не злив рахунок. Тому бот орієнтується на задокументовані стратегії, а не на ТОП рейтингу.
- Перш ніж думати про реальні гроші, потрібно щонайменше 2–3 місяці паперової торгівлі.
